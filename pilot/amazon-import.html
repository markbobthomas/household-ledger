Amazon purchase import

Automatically assign budget categories using the items you bought, not just the bank's generic “Amazon” description. This imports categories only—not new expenses or changes to balances.

Upload Amazon order history

In Amazon, request your personal information for Orders, download the resulting ZIP, then upload it here. A CSV containing item-level order history also works. Select the file named Retail.OrderHistory if uploading a single CSV.

Private: your file is processed only by Ledger's authenticated server. No Amazon password is needed, and nothing is sent to an AI provider. Maximum file size: 79 MB. Ledger uses only orders near Amazon charges that still need categorization.

Preview

Only clear one-to-one Amazon charge matches are applied. Manual category decisions are preserved. Unrecognized items remain Unassigned for Review. Bank payments and balances are never edited.

Sync Amazon orders from your browser

On a desktop computer, you can use the Ledger Amazon browser extension (Chrome / Edge) to read orders while signed in to Amazon and open this same preview automatically—without waiting for an Amazon data export.

This initial browser sync is deliberately conservative: it handles clearly priced single-item orders from up to five order-history pages. Multi-item orders and uncertain totals still need an Amazon CSV/ZIP export. Nothing is saved until you press Apply categories. Desktop browser required; iPhone/iPad browser extensions are not supported.

How matching works

  • Finds Amazon charges in your existing bank history using the exact charged amount and a reasonable order-to-posting window.
  • Splits one charge across budget categories when multiple different items were purchased.
  • Does not guess when charges, shipping splits, refunds, or multiple matching orders make a match uncertain.
  • Reimporting the same history will not add expenses or duplicate category allocations.
