Automatic Amazon updates

Keep product names up to date without leaving your computer on. Ledger checks for new Amazon bank charges Monday, Thursday and Saturday. TinyFish opens Amazon only when there is something new to match.

No new Amazon charges means no TinyFish browser charge. Ledger requests a 45-step limit (roughly $0.75 at current TinyFish rates). If TinyFish cannot enforce the limit for your account, Ledger will not start a paid browser run.

Set up once

  1. Connect Amazon. Open TinyFish, open your saved browser profile, sign in to Amazon, and save that sign-in. You do not enter an Amazon password into Ledger.
  2. Connect TinyFish. In TinyFish, copy an API key. Paste it below. Ledger stores it privately in its encrypted settings.
  3. Turn on updates. Ledger will do the rest on scheduled days, even when this page is closed.

Cost, privacy and what gets matched

The cloud browser can read your Amazon order pages but never your bank account. Ledger checks order IDs, prices and dates against existing posted bank charges. No duplicate expenses or guessed matches. Split orders and uncertain items remain available for review.

Automatic checks require a working bank connection and a TinyFish Amazon sign-in. If Amazon requests verification or TinyFish runs out of funds, updates pause for attention. Turning updates off stops future new runs; a browser run already started may finish and cost money.

The ZIP/CSV import above remains available for complete order history.

Details and other import options

Confirmed matches use amounts and dates and can split one posted charge among product categories. Possible and date-only matches remain clearly labeled. Existing handwritten Notes, manual category choices and all bank amounts remain untouched.

Cloud Amazon updates are configured above. The manual importer remains available if Amazon cannot be read automatically.

Saved Amazon matching quality

Counts use your current saved posted Amazon charges, not the number of products uploaded. No data is sent to AI to calculate these figures.

Checking saved matches…

Manual and AI-reviewed counts describe saved choices, not proof a category was correct. Unidentified or uncertain charges may need another Amazon export or your review. Existing specific categories are protected.
