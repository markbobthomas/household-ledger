Connect Amazon to TinyFish — step by step

No computer extension or programming required. You only need to set this up once.

  1. Recognize the TinyFish home screen.

    If TinyFish shows “What do you want your agent to do?”, you are in its Agent Playground. That is normal, but do not type an Amazon task or press Run. A one-time agent task does not save the reusable Amazon login that Ledger needs.

  2. Open the saved-logins page directly.

    Tap Open TinyFish saved profiles below. Sign in to TinyFish if asked. This opens the separate saved-browser-sessions page directly, so you do not need to find a TinyProfiles menu inside the Agent screen.

    Open TinyFish saved profiles
    That link doesn't show saved profiles?

    If it redirects you to the “What do you want your agent to do?” box, gives an error, or does not offer saved profiles, stop setup here. Do not pay for an Agent task or assume typing instructions will save your login. Your TinyFish interface may not expose the feature Ledger needs.

    See TinyFish's official illustrated saved-profile setup. If the profile page still is not available, contact TinyFish about access or use the manual Amazon ZIP/CSV import below. Leave automatic updates OFF until a saved Amazon session is available.

  3. Create or open an Amazon profile.

    On the saved profiles page, choose Create profile if you do not already have one for Amazon. Name it Ledger Amazon and select Next. Choose Open a browser and sign in. If you already have an Amazon profile, open its setup/sign-in option instead.

    Mark that profile as Default in TinyFish. Ledger checks for a default saved Amazon profile when you connect.

  4. Sign in to Amazon in the setup browser.

    In the browser TinyFish opens, enter https://www.amazon.com/your-orders into its website-address field and select Open. Sign in on Amazon's page and enter any verification code Amazon asks for. Make sure you can see Your Orders.

    Only enter your Amazon password on Amazon's sign-in page inside TinyFish. Never paste an Amazon password into Ledger or the Agent prompt.

  5. Save the Amazon login.

    Back in TinyFish, select Save when it confirms the session was captured. Check that the saved profile shows amazon.com — Signed in (wording may vary) and that the profile is marked Default. Do not just close the setup browser.

  6. Open TinyFish API Keys.

    Use the direct link below. In the same TinyFish account, select Create API Key and, if asked, name it Ledger Amazon.

    Open TinyFish API Keys
  7. Copy the new API key.

    Tap Copy beside the key TinyFish creates. Keep this private. It is a connection code, not your Amazon password, and TinyFish may show it only once.

  8. Paste the API key here in Ledger.

    Return to this Ledger page. Paste the copied key into the box below and tap Connect TinyFish. Ledger checks the key and the saved default Amazon profile without starting a paid Agent job. Wait for TinyFish connected.

  9. Turn on updates in Ledger.

    Once Ledger says TinyFish connected, use Turn on automatic updates below. Look for Automatic updates ON. Only new posted Amazon charges going forward can start a scheduled check; older purchases are not automatically scanned.

Last check and troubleshooting

Cost, privacy and what gets matched

TinyFish reads Amazon order pages, not your bank account. Ledger privately matches order details to existing posted bank charges; it never creates a second purchase or rewrites bank balances. Only exact matches can add product Notes/categories automatically. Uncertain purchases stay for review.

First setup starts with new charges going forward, not a surprise paid import of old history. Each run requests a 45-agent-step and 10-minute limit (roughly $0.74 at the current published rates, not an exact bill). If TinyFish does not support that limit on your account, Ledger will not run uncapped. A maximum of 13 browser starts is permitted in any rolling 30 days, including Check now.

If Amazon needs a new sign-in, a run fails, no valid orders are returned, or no orders match bank charges, updates turn OFF and show a problem instead of silently retrying. Turn them back on only after checking the problem. A run already started may still finish and incur charges.
