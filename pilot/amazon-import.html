Amazon purchase import

Match Amazon purchases to your existing bank charges, add the actual product names to transaction Notes, and assign categories when confident. Existing personal notes and bank balances are never changed.

Upload Amazon order history

In Amazon, request your personal information for Orders, download the resulting ZIP, then upload it here. A CSV containing item-level order history also works. Select the file named Retail.OrderHistory if uploading a single CSV.

Private: your file is processed only by Ledger's authenticated server. No Amazon password is needed, and nothing is sent to an AI provider. Maximum file size: 79 MB. Ledger checks posted Amazon charges missing an item Note or a category.

Preview

Exact, unique purchase matches receive item Notes and confident categories. Possible matches receive Notes beginning “Possible Amazon:” to show they need verification; they never set a category. Existing personal Notes and manual categories are preserved. No bank transactions or balances are edited.

Sync Amazon orders from your browser

On a desktop computer, you can use the Ledger Amazon browser extension (Chrome / Edge) to read orders while signed in to Amazon and open this same preview automatically—without waiting for an Amazon data export.

This initial browser sync is deliberately conservative: it handles clearly priced single-item orders from up to five order-history pages. Multi-item orders and uncertain totals still need an Amazon CSV/ZIP export. Nothing is saved until you press Apply categories. Desktop browser required; iPhone/iPad browser extensions are not supported.

How matching works

  • Matches whole orders, individual items and combinations of items shipped on the same day. Near-amount or date-only suggestions are clearly marked as unverified in Notes.
  • Splits one charge across budget categories when multiple different items were purchased.
  • Never assigns an uncertain item to a budget category. If several purchases plausibly fit a charge, Ledger leaves it unmatched instead of claiming a specific purchase.
  • Existing personal Notes are never overwritten. Reimporting does not add expenses or duplicate allocations.
