Ledger's $0.08 paid-category AI approval is distinct from TinyFish browser fees.

### 2026-11-27 — Conditional TinyFish cost estimate for Amazon charges (design only)

**Verified fees:** TinyFish wallet shows Agent $0.016/step and Browser $0.002/min. For 30 purchases/week, use a nonbinding 3-run/week model at 50, 120 and 250 agent steps weekly plus 30 total browser minutes: about $3.73, $8.58 and $17.59 per 52/12-month. Order count is not a direct step count; multi-item orders and login challenges may raise it. Suggest budget $10–$20/mo and test a read-only run before selecting an enforced per-run max (initial candidate ~$1). Actual Amazon account behavior and cost are still unverified.
**Conditional trigger:** Start only if a NEW, unmatched, posted Amazon bank transaction appears after a *successful* Plaid transaction sync, excluding pending→posted replacement, previously imported exact matches, prior successful decision and unrelated Amazon refunds. Aggregate several charges into ONE cloud run, no more than about three times weekly; when zero new eligible charges skip cloud browser entirely. A failed run remains visible/retryable under clear cooldown and spending rules. TinyFish does not itself subscribe to private Ledger/Plaid changes.
**Prerequisite:** The existing hourly server maintenance is forecast re-preparation, not bank fetching. For a PC-independent condition, add authenticated/verified Plaid `SYNC_UPDATES_AVAILABLE` webhook plus `/transactions/sync` or separate scheduled bank polling; webhook announces available changes but not that they are specifically Amazon. Add a narrow private status + revocable import-only mechanism instead of exposing bank credentials to cloud browser. Docs-only; no paid runs, settings, provider credentials, sync jobs or production changes; runtime tests not applicable.
